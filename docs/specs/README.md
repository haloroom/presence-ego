# Feature Specifications

## 개요

기능 명세서를 관리합니다. 새 스펙은 `docs/specs/_template.md`를 복사하여 작성합니다.

## 작성 프로세스

1. `_template.md` 복사 → `feature-name.md`로 이름 지정
2. 요구사항, 수락 기준, 엣지 케이스 작성
3. 관련 ADR 연결
4. 리뷰 후 status를 `Approved`로 변경
5. 구현 완료 후 status를 `Implemented`로 변경

## 상태 정의

| Status | 의미 |
|:---|:---|
| Draft | 작성 중 |
| In Review | 리뷰 대기 |
| Approved | 구현 대기 |
| Implemented | 구현 완료 |
| Deprecated | 폐기됨 |
