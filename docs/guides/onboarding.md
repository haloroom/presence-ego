# Onboarding Guide (온보딩 가이드)

## AI 에이전트를 위한 온보딩

### 1단계: 프로젝트 이해
1. `README.md` 읽기 → 프로젝트 개요 파악
2. `AGENTS.md` 읽기 → 핵심 지침 이해
3. `docs/ARCHITECTURE.md` 읽기 → 구조 이해

### 2단계: 상태 확인
1. `.state/PROJECT_STATUS.md` → 현재 진행 상황
2. `.state/SESSION_LOG.md` → 최근 작업 내역
3. `.state/KNOWN_ISSUES.md` → 알려진 이슈

### 3단계: 작업 시작
1. `.state/SESSION_LOG.md`에서 이전 세션 핸드오프 노트 확인
2. 관련 `docs/specs/` 참조
3. 코딩 시작

### 4단계: 작업 종료
1. `.state/CHANGELOG.md` 업데이트
2. `.state/SESSION_LOG.md` 핸드오프 노트 작성
3. 주요 결정 시 `docs/adr/` 기록

## 사람 개발자를 위한 온보딩

### Quick Start
1. 위 파일들을 순서대로 읽기
2. `docs/CONVENTIONS.md`로 코딩 규약 파악
3. `docs/TECH_STACK.md`로 기술 스택 확인

### AI 도구 설정
| 도구 | 설정 방법 |
|:---|:---|
| **Antigravity** | `.agents/AGENTS.md` 자동 인식 |
| **Claude Code** | `CLAUDE.md` 자동 인식 |

### 프로젝트 철학
이 블로그는 에크하르트 톨레의 'A New Earth'에서 영감받았습니다.
- **현존(Presence)**: 지금 여기에 깨어있는 진짜 나
- **에고(Ego)**: 생각과 동일시하는 가짜 나
- 둘 사이를 탐구하며 진실되게 나를 바라보는 기록입니다.
