# Glossary (프로젝트 용어 사전)

## 프로젝트 철학 용어

| 용어 | 정의 |
|:---|:---|
| **현존 (Presence)** | 에크하르트 톨레가 말하는 '지금 여기'에 깨어있는 상태. 생각이 아닌 의식 자체로서의 나 |
| **에고 (Ego)** | 생각, 감정, 기억, 역할과 나를 동일시하는 마음의 구조. 톨레가 말하는 '가짜 나' |
| **내려놓음 (Letting Go)** | 생각과의 동일시를 놓아버리고, 있는 그대로를 받아들이는 행위 |
| **관찰자 (Observer)** | 생각을 바라보는 의식. 생각하는 자가 아닌 생각을 알아차리는 자 |
| **고통체 (Pain Body)** | 과거의 축적된 감정 에너지. 톨레의 개념으로 무의식적으로 활성화되어 부정적 패턴을 반복 |
| **A New Earth** | 에크하르트 톨레의 저서. 이 프로젝트의 핵심 영감 |

## AI Coding Infrastructure Terms

| 용어 | 정의 |
|:---|:---|
| **Context Engineering** | AI에게 제공하는 전체 정보 환경을 체계적으로 설계하는 분야 |
| **Progressive Disclosure** | AI가 필요한 깊이의 정보만 점진적으로 접근하는 패턴 |
| **Memory Bank** | 세션 간 상태를 Markdown 파일로 영속화하는 패턴 |
| **Handoff Protocol** | AI 세션 종료 시 다음 세션을 위한 컨텍스트 전달 절차 |
| **Token Budget** | 각 문서 파일의 최대 줄 수 제한 |
| **ADR** | Architecture Decision Record. 아키텍처 결정 기록 |

## Content Categories

| 카테고리 | 설명 | 예시 |
|:---|:---|:---|
| **reading** | 책 리뷰, 독서 노트 | 'A New Earth' 리뷰 |
| **study** | 학습한 내용 정리 | TypeScript 패턴 정리 |
| **reflection** | 내면 탐구, 느낌 기록 | 에고를 알아차린 순간 |
| **essay** | 자유 에세이 | 현존과 일상의 관계 |

## Status Values

| Status | 의미 | 사용 위치 |
|:---|:---|:---|
| `Draft` | 작성 중 | specs, content |
| `Approved` | 승인됨 | specs |
| `Implemented` | 구현 완료 | specs |
| `Accepted` | 수락됨 (변경 불가) | ADR |
| `Deprecated` | 폐기됨 | ADR, specs |
